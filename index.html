Work

Key project · Wind, solar & IoT

Hybrid Vertical Axis Wind Turbine

A hybrid renewable-energy system combining wind and solar generation with IoT monitoring. The rotor pairs Darrieus lift blades with a Savonius drag core, so it starts in light wind and still runs efficiently at higher speeds. Solar panels add a second source, and an ESP8266 collects sensor data from the whole system.

Skills developed: renewable-energy system design, sensor integration, embedded hardware and technical documentation.
